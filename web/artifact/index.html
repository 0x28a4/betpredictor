How this market works

“Draw or Over 2.5” wins if the match is a draw or has 3+ goals. It loses on exactly four scorelines: 1-0, 2-0, 0-1, 0-2 — a decisive result with two or fewer goals.

So the model computes it exactly: P = 1 − P(1-0) − P(2-0) − P(0-1) − P(0-2), reading those cells off a Dixon-Coles bivariate-Poisson scoreline grid built from each side's expected goals.

Fixture confidence reflects how well the fixture itself was verified (some lower-division matchups came from stitched search results). Probabilities are the live in-browser model.
